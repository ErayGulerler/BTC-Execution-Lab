# Market data

The original, unmodified archive contains BTCUSDT spot one-minute bars for June 2024. Binance Vision publishes it with a SHA-256 checksum. The replay verifies the hash and all 43,200 minute timestamps before selecting its six daily windows. The source timestamps for this June 2024 file are Unix milliseconds in UTC.
